# OOTP Multi-Tool

**The little tool to make OOTP better.**

An unofficial companion tool for **Out of the Park Baseball 2027**, built for
historical sim players who want deeper immersion and the pieces to build their
own historical sandboxes.

**Download and full details: [justtxyank.com/downloads/ootp-multi-tool](https://justtxyank.com/downloads/ootp-multi-tool/)**

## Features

**Available now**

- **Database converter** — opens the historical database files so you can edit
  them directly, then repacks them into a format the game reads.

**In development**

- Save game editing — validate managers in an existing save
- Historical team corrections — fix teams that don't match the historical record
- Historic Draft Class Builder — draft classes that fit the era you're playing
- Historic Owners Builder — period-accurate ownership for your league

Planned features are not in the current build. This list is updated as each
one lands.

## Before you use it

**Back up your save and your OOTP data folder first.** This tool edits your
game's database files, and there is no undo button for a file you overwrote.

Provided as is, without warranty of any kind. Use at your own risk.
